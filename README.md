# TechMart
Tech Mart is a mini E-Commerce web application built with Flask (Python) and SQLite. It allows users to register, login, search electronic products, add them to a cart, and place orders. The app uses Flask for backend, HTML/CSS with Jinja2 for frontend, and SQLite database to store users, products, carts, and orders.


Technology used:-
Frontend → HTML, CSS, Bootstrap (for styling and responsive design)

Backend → Flask (Python microframework)

Database → SQLite (lightweight DB)

Templates → Jinja2 (for dynamic pages)
